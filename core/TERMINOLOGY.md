# Terminology

This document is the single authoritative terminology dictionary for Loop Engineering. It defines only the official terms, their meanings, and prohibited ambiguous alternatives. Role names must be used exactly as listed; they do not create aliases or assign roles by themselves.

| Official term | Meaning | Prohibited ambiguous alternatives or usage |
| --- | --- | --- |
| project-roadmap-chatgpt | The explicitly assigned role responsible for the project goal, Stage definition, Task definition, acceptance, Result evaluation, and continuation or termination decisions. | Do not substitute Project Controller, Project Manager, Coordinator, or Supervisor for this role name. |
| Launcher | The explicitly assigned role responsible for reading collaboration rules and Stage context, creating Executor, maintaining Stage lifecycle, and handling STOP. | Do not use this name for a role that evaluates Results, judges execution quality, or makes project decisions. |
| Executor | The explicitly assigned role responsible for bounded Task execution, validation, and generation of TASK_EXECUTION_RESULT. | Do not use this name for a role that defines successor Tasks or makes continuation or termination decisions. |
| Stage | A Loop lifecycle concept defined by project-roadmap-chatgpt and maintained by Launcher; its context is known to those roles. | Do not use Stage as another name for Task or as a collaboration message, protocol, or state machine. |
| Task | A bounded unit of execution whose identity, objective, scope, and acceptance are defined by project-roadmap-chatgpt. | Do not use Task as another name for Stage, an entire project, or an informal discussion. |
| TASK_EXECUTION_RESULT | The existing structured message generated by Executor to report bounded Task execution and validation facts directly to project-roadmap-chatgpt. References to Result in the Contract refer to this message. | Do not use an informal report as a substitute for this message, or treat its completion status as project acceptance, Stage completion, or a continuation decision. |
| Loop | The lifecycle from project-roadmap-chatgpt initialization through Stage creation, Launcher initialization, Task execution, Result evaluation, and a continuation or STOP decision. | Do not use Loop to mean one Task execution or an automatic retry process. |
